纸间 0.3.2

启动
  双击「启动纸间.cmd」。
  程序会在首次启动时把运行文件放到 C:\Users\Public\Zhijian，
  再从该路径打开窗口。这样做是为了避开中文路径下 .NET 运行时的
  一个已知限制。之后再次启动会直接复用；新版本会自动覆盖旧版本。

设置
  右上角的滑块图标可打开设置：
  外观（跟随系统 / 浅色 / 深色）、字号（小 / 标准 / 大）、自动保存开关。
  设置会保存在本机，下次启动继续生效。

公式
  阅读视图支持 $...$、$$...$$、\(...\)、\[...\] 公式。
  编辑视图保留 Markdown 源文本。

目录大纲
  点右上角的大纲图标，或按 Ctrl+Shift+O。
  点击标题可跳到编辑器对应行或阅读视图对应位置。

打开方式
  设置 → 打开方式 → 设为默认，按系统提示选择纸间并勾选始终使用。

直接运行
  也可以把 Zhijian 文件夹放到一个只含英文字母的路径中，
  直接双击 Zhijian.exe。
  Windows 首次运行未签名程序时，如出现“未知发布者”提示，
  选择“更多信息 → 仍要运行”。

文件
  Markdown 文件始终保存在原位置，不会复制到程序目录。
  编辑会在停止输入约 0.75 秒后自动保存；磁盘文件被其他程序改动时
  会询问重新载入还是覆盖。
  关闭窗口后，下次启动会恢复上次的标签与分屏。
